# Deployment checklist

- [ ] Confirm `site-config.js` contact inbox is active and monitored.
- [ ] Review capabilities, service scope, and public claims.
- [ ] Review Privacy Notice and Terms of Use draft.
- [ ] Upload all files to the GitHub repository root.
- [ ] Deploy Cloudflare Pages with no framework/build output at repository root.
- [ ] Verify `pages.dev` preview: nav, mobile menu, knowledge search, inquiry email builder, footer.
- [ ] Confirm `tacib.net` custom domain and TLS status.
- [ ] Set up and test `www.tacib.net` redirect.
- [ ] Check official outbound resources still resolve and fit the intended audience.
- [ ] Check mobile layout and keyboard focus.
- [ ] Add redirects from old Jimdo URLs where supported.
- [ ] Re-test after publishing.
