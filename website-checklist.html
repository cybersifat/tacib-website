PRACTICAL CYBER SAFETY
GUIDE · EDUCATION

A baseline website security checklist.

This is a starting point for small websites and project owners. It is not a penetration test, certification, or proof that a site is secure.

Identity and access

  • Enable multi-factor authentication on registrar, DNS, hosting, source control, and email accounts.
  • Use unique passwords in a password manager; remove dormant accounts and unnecessary access.
  • Keep domain ownership and recovery details current. Store recovery codes securely.
  • Review repository visibility and ensure no API keys, tokens, passwords, or private customer data are committed.

Updates and backups

  • Keep the website platform, dependencies, plugins, and runtime supported and patched.
  • Maintain a backup or source-controlled copy of important content and configuration.
  • Test how to restore an earlier known-good version.
  • Remove unused components and unnecessary services.

HTTPS and security configuration

  • Ensure the preferred domain and HTTPS certificate work, including the chosen www or non-www version.
  • Redirect visitors consistently to one canonical hostname.
  • Review HTTP security headers appropriate to the site and test changes before deploying.
  • Avoid exposing environment files, backups, admin endpoints, test pages, or directory listings.

Email and domain hygiene

  • Know which email provider handles the domain and preserve its required MX records.
  • Set up SPF, DKIM, and DMARC according to the provider's instructions; avoid publishing conflicting SPF records.
  • Keep registrar and DNS recovery protected by MFA and verified contact details.

Logging, privacy, and response

  • Know which technical logs are retained and who can access them.
  • Collect only the personal data actually needed.
  • Decide who owns incident decisions and where to report hosting or security issues.
  • Display truthful contact details and do not publish policies that describe controls you have not implemented.
For TACIB.net: verify both tacib.net and www.tacib.net, the Cloudflare Pages custom-domain status, and the real contact inbox after each major deployment.

A checklist reduces common risks but cannot guarantee security. A proper technical assessment needs agreed scope and evidence.
